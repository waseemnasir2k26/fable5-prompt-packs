# Changelog

All notable changes to this project are documented in this file.

## [2026.09] - 2026-09-16

- Maintenance review of fable5-prompt-packs — a distribution repo holding 10 niche-targeted "Fable 5 prompts" PDF lead-magnet packs.
- Status: content-only repo, no code and no build. One folder per audience (accountants, agency owners, coaches, creators, ecom, HR ops, local biz, real estate, recruiters, video editors), each containing a single PDF of 10-15 prompts. PDFs were generated 24 July 2026 via headless Chrome print-to-PDF; the last commit removed the expired Fable 5 July-19 deadline from all 10 packs.
- Reviewed September 2026: a README and CHANGELOG were added and the repo versioned as v2026.09. No PDF was regenerated or edited.
- Known gaps: the repo had no README, no CHANGELOG and no LICENSE; only the rendered PDFs are tracked — the HTML/Markdown sources they were printed from are not in this repo, so a pack cannot be regenerated from here.
